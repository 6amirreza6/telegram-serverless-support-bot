ربات پشتیبانی تلگرام را در چند دقیقه راه‌اندازی کنید

این صفحه اطلاعات لازم (آیدی مدیر، ادمین‌ها، دسته‌بندی‌ها و تنظیمات) را در مرورگر خودتان جمع می‌کند، یک پروژه آماده استقرار می‌سازد و شما آن را با CLI ACCESS روی سرورلس تلگرام پوش می‌کنید.

🔒 کاملاً سمت کلاینت — هیچ داده‌ای به هیچ سروری ارسال یا ذخیره نمی‌شود. همه‌چیز در مرورگر شما می‌ماند.

دریافت توکن CLI ACCESS از BotFather

CLI ACCESS قابلیتی است که به شما اجازه می‌دهد کد ربات را از ترمینال خودتان روی زیرساخت تلگرام مستقر کنید. توکن آن فقط از BotFather صادر می‌شود:

  1. وارد ربات @BotFather شوید و ربات خود را انتخاب کنید (یا یک ربات جدید بسازید).
  2. روی دکمه Serverless بزنید و آن را برای رباتتان روشن کنید.
  3. گزینه CLI Access را باز کنید و توکن دسترسی CLI را کپی کنید.
  4. توکن را همین‌جا نگه دارید — در مرحله ۴ هنگام اجرای npx tgcloud login به آن نیاز دارید.
🤖 باز کردن BotFather در تلگرام

⚠️ این توکن فقط در حافظه همین مرورگر می‌ماند؛ داخل فایل zip ساخته‌شده قرار نمی‌گیرد و هیچ‌جا ارسال نمی‌شود.

2

تنظیمات ربات خود را وارد کنید

همه فیلدها اختیاری‌اند. مقادیری که وارد کنید در زمان استقرار مستقیماً داخل دیتابیس ربات بارگذاری می‌شوند (Seed) — نه در GitHub و نه در هیچ جای کد.

آیدی عددی خود را از @userinfobot بگیرید. اگر خالی بگذارید، بعداً با جریان امن /setup مالکیت را ادعا می‌کنید.

هر کاربر می‌تواند زبان خودش را عوض کند؛ این فقط زبان شروع است.

ادمین‌ها به تیکت‌ها پاسخ می‌دهند ولی نمی‌توانند ادمین اضافه کنند یا تیکت را حذف کنند.

دو زبانه وارد کنید (فارسی + English). اگر حداقل یک دسته بدهید، سیستم دسته‌بندی خودکار فعال می‌شود.

⚙️ تنظیمات پیشرفته (اختیاری)
3

ساخت و دانلود پروژه آماده استقرار

سورس کامل ربات + فایل تنظیمات شخصی شما (seed-config.js) داخل یک فایل zip ساخته می‌شود — همه‌چیز همین‌جا در مرورگر.

4

استقرار روی سرورلس تلگرام با CLI

فایل zip را در یک پوشه جدید باز کنید، سپس این دستورها را به ترتیب در همان پوشه اجرا کنید (Node.js 18+ لازم است):

npm install
npx tgcloud login

↳ توکن CLI Access مرحله ۱ را اینجا بچسبانید.

npx tgcloud push
npx tgcloud migrate
npx tgcloud run lib/seed

↳ تنظیماتی که در مرحله ۲ وارد کردید (مالک، ادمین‌ها، دسته‌ها) را داخل دیتابیس ربات بارگذاری می‌کند.

راه جایگزین برای مالکیت (بدون نوشتن آیدی)

اگر آیدی خود را وارد نکرده‌اید، بعد از migrate این دو مرحله را انجام دهید: اول npx tgcloud run lib/setup-key روی کامپیوتر، بعد ارسال /setup KEY به ربات در تلگرام (کلید ۳۰ دقیقه اعتبار دارد و یک‌بارمصرف است).

🎉 تمام شد!

ربات خود را در تلگرام باز کنید، /start بزنید و با /panel وارد پنل مدیریت شوید. همه تنظیمات بعداً هم از داخل خود ربات قابل تغییر است.

🛡

نکات امنیتی

  • توکن CLI ACCESS را با کسی تقسیم نکنید؛ هر کس توکن را داشته باشد می‌تواند کد ربات شما را عوض کند. اگر لو رفت، از BotFather آن را بازتولید کنید.
  • فایل zip ساخته‌شده شامل tgcloud/lib/seed-config.js با آیدی‌های شخصی شماست — آن را فقط روی سیستم خودتان نگه دارید و در هیچ مخزنی پابلیش نکنید (در همین پروژه gitignore شده است).
  • این صفحه هیچ بک‌اند، آنالیتیکس یا کوکی ندارد؛ می‌توانید قبل از استفاده سورس آن را در پوشه docs/ مخزن بررسی کنید.
  • برای مالکیت، جریان /setup با کلید یک‌بارمصرف امن‌ترین گزینه است؛ وارد کردن آیدی در مرحله ۲ صرفاً راحت‌تر است.
❓

سوالات پرتکرار

آیا این سایت چیزی روی GitHub یا جایی دیگر ذخیره می‌کند؟

نه. صفحه فقط HTML/JS استاتیک است؛ فرم‌ها در حافظه مرورگر پردازش و فایل zip همان‌جا ساخته می‌شود. هیچ درخواستی به هیچ سروری ارسال نمی‌شود (فقط فونت و کتابخانه zip از CDN خوانده می‌شود).

چرا سایت خودش مستقیماً روی سرورلس تلگرام پوش نمی‌کند؟

پروتکل CLI ACCESS برای اجرا از ترمینال شما طراحی شده و از مرورگر (به‌دلیل CORS) قابل فراخوانی نیست. به همین دلیل این صفحه پروژه آماده را می‌سازد و دستورهای دقیق CLI را می‌دهد — کل استقرار با ۵ دستور انجام می‌شود.

بعداً چطور تنظیمات را عوض کنم؟

ادمین‌ها، دسته‌بندی‌ها، بستن/حذف تیکت و همه‌چیز از داخل پنل خود ربات قابل مدیریت است. برای تغییر محدودیت‌ها یا منطقه زمانی، فایل config.js پروژه را ویرایش و دوباره push کنید.
